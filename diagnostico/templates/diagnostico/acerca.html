Cómo se construyó el modelo

Metodología

Clasificación de imágenes de hojas de café robusta con una red neuronal convolucional preentrenada (transfer learning).

El problema

La roya y el ácaro rojo reducen la productividad del café. Detectarlos a tiempo por inspección visual exige personal entrenado y recorrer todo el cultivo. El objetivo es clasificar automáticamente una foto de hoja en tres clases: sana, roya o ácaro rojo.

Dataset: RoCoLe

Robusta Coffee Leaf Images: fotografías de hojas de café robusta tomadas en campo con smartphone, etiquetadas por expertos. Versión de Kaggle con 1.560 imágenes: 791 sanas, 602 con roya y 167 con ácaro rojo.

Pipeline

  1. Partición por planta. Las fotos de una misma planta (prefijo C#P#) quedan en una sola partición: StratifiedGroupKFold → entrenamiento {{ m.distribucion_totales.train }}, validación {{ m.distribucion_totales.val }}, prueba {{ m.distribucion_totales.test }}. Así se evita fuga de datos.
  2. Preprocesamiento. Redimensionado a 224×224 y escalado de píxeles a [-1, 1].
  3. Aumento de datos. Volteos, rotación, zoom, contraste y brillo aleatorios.
  4. Desbalance. Pesos de clase balanceados (el ácaro rojo pesa ≈3,1 veces más).
  5. Fase 1. MobileNetV2 (ImageNet) congelada; se entrena solo la cabeza (GlobalAveragePooling + Dropout 0,3 + Dense softmax), Adam 1e-3.
  6. Fase 2 · Fine-tuning. Se descongelan las últimas 30 capas de MobileNetV2 y se entrena con Adam 1e-5, EarlyStopping y ReduceLROnPlateau.
  7. Fase 3 · Ajuste fino adicional. Se continúa con Adam 5e-5; EarlyStopping (paciencia 8) restaura los pesos con menor pérdida de validación.
  8. Selección del modelo. Entre los modelos guardados se eligió el de mejor accuracy en validación; el conjunto de prueba se usó solo para el reporte final.
  9. Despliegue. El modelo se convierte a TensorFlow Lite (≈2,5 MB) y se sirve con Django en Render.

API

Además de la interfaz web, la app expone un endpoint para integrarla con otros sistemas:

curl -X POST -F "imagen=@hoja.jpg" {{ request.scheme }}://{{ request.get_host }}/api/predecir/

Respuesta JSON con la clase predicha y la probabilidad de cada clase.
